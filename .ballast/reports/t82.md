- There's now a one-command smoke test that plays one night in Pine Hollow with the real controls, so a broken hunt is caught before anyone plays it: run `npm ci` then `npm run smoke`.
- It checks five things in order, each printing PASS or FAIL. Clicking in starts the night and the clock runs. Holding W walks you forward. Walking up to a clue, aiming and pressing E logs it in the field journal. Raising the camera with right mouse and clicking photographs Bigfoot, and the hunt switches to "get back to the van". Pressing H at the van ends the hunt as complete and shows the results screen. Any failed step or page error makes it fail.
- It passes from a fresh clone of the repo (5/5, no page errors) and takes about 3 minutes in software rendering. Screenshots of each step are in this task's captures folder. How to run it is in the README.
- Shortcuts it takes: it jumps between the scenes instead of walking the whole map, uses a fixed world seed, and stops Bigfoot from catching you, so the test doesn't depend on where he wanders. It isn't wired into an automatic build check yet. Another task (#81) is setting up the repo's automatic checks; `npm run smoke` is the command to add there.
