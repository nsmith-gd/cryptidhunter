## Questions
### How chunky should the pixels feel up close?
Context: Textures are painted at about 3 cm per pixel, so a tree trunk at arm's length shows bark plates a few pixels across and the dirt trail shows individual pebbles; far away it settles into a smooth image.
Options: - 3 cm pixels (current: detailed but clearly pixel art, like the boardwalk reference) - 6 cm pixels (bolder, chunkier, more retro like the dungeon reference, less fine detail) - 1.5 cm pixels (finer and more realistic, the pixel feel fades)
Going with: 3 cm, the balance between the reference images; changing it later means repainting textures, so worth settling early.
