STATUS: DONE
- Every pixel on screen is now exactly the same size. The game renders a low-resolution image (640×360 on a 1080p screen, the style guide's target; about 360 rows on any screen) and blows it up by a whole number with hard pixel edges. Before, the image was stretched by an uneven amount, so some pixels were 3 screen-pixels wide and others 4, and that uneven pattern crawled across the screen whenever you moved. Any leftover sliver at the screen edge is a thin black border.
- Looking around no longer shimmers. The view now turns in whole-pixel steps: tiny mouse movements, and the gentle fear and comfort sway, no longer make tree edges, needles and fences flicker. Turning feels the same, because each step is a fifth of a degree at 1080p. Aiming, photos and gameplay still use your exact aim. Walking stays perfectly smooth; that's normal parallax, not shimmer.
- Measured in the forest: a turn smaller than one pixel now changes 0 pixels (before: 22,000 to 44,000 of the 130,000 re-drawn). Over a slow, steady pan of 47 frames, the image changes on only 7 frames, one clean step each, instead of crawling on every frame.
- Night vision and future colour grading run on the same low-resolution image, so they stay pixel-crisp too.
- To see it: `npm run dev` and look around slowly in `?map=forest`; add `?nosnap` to compare with snapping off. `npm run check:t35` runs the measurements. Captures in `.ballast/media/t35/`: `02-slow-pan-...gif` shows a magnified patch of forest during a slow pan, snapped on the left and the old behaviour on the right; `03` is the full-screen slow pan; `01` is a still.

## Questions
### How chunky should the pixels be?
Context: The game draws about 360 rows of pixels and scales them up, so on a 1080p screen each game pixel is a 3×3 block. Distant trees, tracks and the cryptid's outline are built from these blocks.
Options: - Chunkier (about 270 rows: more retro, distant clues and silhouettes harder to read) - Current (about 360 rows, the style guide target) - Finer (about 480 rows: more detail, less of the pixel-art feel)
Going with: Current, the style guide's choice: chunky enough to read as pixel art, fine enough to spot tracks.
